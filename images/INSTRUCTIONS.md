# Hướng dẫn thêm hình ảnh xúc xắc

## Cách 1: Tải hình ảnh có sẵn

Bạn cần thêm 6 file hình ảnh xúc xắc vào thư mục này với tên:
- dice1.png
- dice2.png
- dice3.png
- dice4.png
- dice5.png
- dice6.png

### Nguồn tải hình miễn phí:

1. **Từ GitHub của Angela Yu (khóa học Flutter gốc):**
   - https://github.com/londonappbrewery/dicee-flutter

2. **Tạo hình đơn giản online:**
   - https://www.flaticon.com/search?word=dice
   - https://www.pngwing.com/en/search?q=dice

3. **Hoặc sử dụng AI để tạo:**
   - Dùng bất kỳ công cụ AI tạo hình nào để tạo 6 mặt xúc xắc

## Cách 2: Dùng phiên bản Unicode (không cần hình)

Nếu không muốn dùng hình, tôi có thể sửa code để dùng emoji xúc xắc: ⚀ ⚁ ⚂ ⚃ ⚄ ⚅

## Sau khi có hình:

1. Copy 6 file vào thư mục `images/`
2. Chạy lệnh: `flutter pub get`
3. Chạy ứng dụng: `flutter run`
