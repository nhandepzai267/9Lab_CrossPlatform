# Lab 9 – Clima 🌤️

A Flutter weather app that fetches **live data** from the [OpenWeatherMap API](https://openweathermap.org/api). Enter any city name to instantly see current temperature, weather condition, humidity, feels-like temperature, and wind speed — all styled with a clean blue gradient UI.

## Setup

1. Get a free API key at [openweathermap.org](https://openweathermap.org/api)
2. Replace `YOUR_API_KEY_HERE` in `lib/services/weather_service.dart`
3. Run `flutter pub get` then `flutter run`
