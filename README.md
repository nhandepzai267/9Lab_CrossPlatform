# 🧠 Quizzler

Một ứng dụng quiz vui vẻ được xây dựng bằng Flutter. Người dùng trả lời 5 câu hỏi Đúng/Sai về các chủ đề thú vị như động vật, khoa học và tự nhiên.

## Tính năng

- 5 câu hỏi Đúng/Sai hài hước và thú vị
- Giao diện tối (dark theme) hiện đại
- Hiển thị icon ✅/❌ theo dõi kết quả từng câu
- Màn hình kết thúc với phản hồi emoji dựa trên điểm số
- Nút chơi lại để thử lại từ đầu

## Cấu trúc code

- `question.dart` — Model lưu nội dung và đáp án câu hỏi
- `quiz_brain.dart` — Logic quản lý danh sách câu hỏi
- `main.dart` — Giao diện người dùng

## Công nghệ

Flutter · Dart
