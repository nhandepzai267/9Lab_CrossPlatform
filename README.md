# Destini – Lab 7

Ứng dụng Flutter theo thể loại **chọn lựa cốt truyện** (choose-your-own-adventure).

## Cốt truyện

Bạn lạc vào một khu rừng tối và đứng trước **ba con đường**:
- 🌲 Bên trái – tiếng suối chảy
- 🏚️ Giữa – ánh lửa từ xa
- ⬆️ Bên phải – mùi hoa dại

Mỗi lựa chọn dẫn đến một kết thúc riêng: **tự do**, **thoát hiểm**, hoặc **khám phá bí ẩn**.

## Tính năng

- 3 nhánh lựa chọn → 3 kết thúc độc lập
- Nút **Chơi lại** để restart từ đầu
- Giao diện tối, đơn giản, không dùng package ngoài

## Chạy ứng dụng

```bash
flutter pub get
flutter run
```
