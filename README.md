# MiCard - Lab 2

Ứng dụng danh thiếp cá nhân (business card) được xây dựng bằng Flutter, thể hiện thông tin liên hệ một cách đẹp mắt và chuyên nghiệp.

## Mô tả

MiCard là một ứng dụng Flutter đơn giản nhưng hiệu quả để tạo danh thiếp điện tử. Ứng dụng hiển thị thông tin cá nhân bao gồm ảnh đại diện, họ tên, số điện thoại và email với giao diện Material Design đẹp mắt.

## Widgets sử dụng

- `Scaffold`: Cấu trúc cơ bản
- `CircleAvatar`: Hiển thị ảnh đại diện
- `Column`, `Row`: Layout widgets
- `Card`, `ListTile`: Hiển thị thông tin
- `Icon`, `Text`: UI components

## Cách chạy

```bash
flutter pub get
flutter run
```
